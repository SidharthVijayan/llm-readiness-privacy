Privacy Policy for LLM Readiness Inspector

Effective Date: April 30, 2026
Last Updated: 19 October 2026

LLM Readiness Inspector is a Chrome extension that analyzes the structure of the web page you are viewing (such as headings, lists and paragraphs) and shows a readiness score with suggested improvements for AI search and LLM-based tools.

Information Collection and Use

This extension does not collect, store, or transmit any personal or sensitive user data. It does not record your browsing history, and it does not use cookies, analytics, or tracking of any kind.

How It Works

The extension runs only when you open its popup and click to analyze the current page. The analysis is performed entirely locally within your browser. The page content it reads is used only to calculate the score shown in the popup and is discarded when the popup is closed. The extension makes no network requests and does not send page content or any other data to any server.

Permissions

The extension requests only the following two permissions:

  • activeTab: grants temporary access to the tab you are currently viewing, and only after you click the extension. It does not give access to any other tabs or websites.
  • scripting: lets the extension run its analysis code on that active tab to read the page's structure.

The extension does not request host permissions, broad website access, or access to your browsing history, tabs, storage, or cookies.

Third-Party Services

This extension does not use any third-party services, and no data is sold, shared, or transferred to third parties.

Data Security

Because no user data is collected, stored, or transmitted, no user data leaves your device.

Changes to This Policy

If this policy changes, the updated version will be posted on this page with a new "Last Updated" date.
